## 🌟 Про проєкт

**`dsh-desktop-ua`** — це адаптована, на 100% локалізована версія десктопної платформи **DeepSeek Harness (DSH Desktop)** із понад **36,000 ⭐** на GitHub. 

Оригінальна програма підтримувала лише спрощену китайську та базову англійську мови, через що користувачі стикалися з неперекладеними системними меню, майстрами налаштування та сповіщеннями. У цьому випуску додано повну підтримку **української** та **російської** мов для всіх модулів:

1. **Майстер першого запуску (Setup Wizard)**: Повний український супровід конфігурації.
2. **Панель налаштувань Desktop**: Управління профілями, параметри вікна, журналювання та логування.
3. **Меню програми та системний трей**: Нативні команди Electron («Вікно», «Вигляд», «Редагувати», «Перезавантажити», «Інструменти розробника»).
4. **Діагностика та аварійне відновлення (Crash Recovery)**: Зрозумілі інструкції у разі збоїв чи експорту звітів.
5. **Магазин плагінів (Community Market)**: Каталог і керування розширеннями.

## ✨ Основні покращення

* 🇺🇦 **Рідна українська локалізація**: Понад 580 текстових рядків перекладено сучасною технічною українською термінологією.
* 🇷🇺 **Російська мова**: Збережено повну підтримку для сумісності з міжнародними користувачами.
* 🖥️ **Нативні Electron-меню**: Меню macOS, Windows та Linux тепер автоматично підлаштовуються під системну мову користувача.
* 🚀 **Очищений пайплайн**: Видалено зайві прив'язки до внутрішніх китайських серверів і сертифікатів.
